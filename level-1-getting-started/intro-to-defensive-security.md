## What the room was about
A simulation of how defensive security works in a safe environment.
How to react to an attack, and how to defend against it.

## Key concepts I learned
- SOC: the team that watches alerts 24/7.
- SIEM: a tool that collects logs and generates alerts.
- Incident response: what a team does when an attack is detected.
