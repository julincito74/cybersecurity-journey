# Search Skills

**Date:** 16/09/2026
**Room:** TryHackMe — Search Skills
**Type:** Methodology / Tooling

## What the room was about
How to use the internet effectively as a cybersecurity professional. Finding reliable information fast is a core SOC skill.

## Tools and techniques I learned

### Shodan
A search engine for internet-connected devices. It finds servers, IoT devices, and services by reading their public banners. Useful for seeing what a suspicious IP is exposing.

### VirusTotal
A platform that analyzes files, URLs, hashes, and IPs using multiple antivirus engines and sandboxes.

### CVE and NVD
CVE is a unique ID for a publicly known vulnerability. NVD provides the severity score and affected versions.

### Man pages
Linux command `man` shows the official documentation for any installed tool. Essential for daily terminal work.

### GitHub
Where security tools and public proof-of-concept exploits are published. Useful to check if a new CVE has a working exploit.

## Why this matters for a SOC Analyst
Every investigation starts with a search. When an alert fires, you receive an indicator (IP, hash, domain) and your first move is to search for information about it. Without fast, reliable search skills, you cannot investigate anything.

## What surprised me
The number of tools used every day in cybersecurity, and how useful each one is for different tasks.
